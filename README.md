# BMI Calculator

A compact Flutter application for calculating Body Mass Index from a user's height and weight. It demonstrates form input, calculation logic, result classification, and a clean mobile interface.

## Built With

- Flutter and Dart
- Material Design widgets
- Android and iOS project targets

## Run Locally

1. Install Flutter and an Android or iOS development toolchain.
2. Confirm that Flutter can see the toolchain:

   ```bash
   flutter doctor
   ```

3. Open a terminal in the repository root and install packages:

   ```bash
   flutter pub get
   ```

4. Start an emulator, simulator, or connect a physical device, then confirm it is available:

   ```bash
   flutter devices
   ```

5. Run the application:

   ```bash
   flutter run
   ```

No backend or API key is required. Use `flutter analyze` to check the source before contributing changes.
